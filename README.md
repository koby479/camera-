# Universal Cam Viewer

תוכנת צפייה אוניברסלית במצלמות אבטחה (ONVIF / RTSP) - תומכת גם ב-NVR (כולל Provision-ISR
עם קושחה שתומכת ONVIF G/T/S) וגם במצלמות בודדות (כולל מצלמות סיניות/Annke שתומכות RTSP/ONVIF).

## מבנה
- `app/core/camera.py` - מודל מצלמה + thread שמושך RTSP ומדווח סטטוס (פעילה/מתה/לא מחוברת)
- `app/core/discovery.py` - שאילתות ONVIF מול NVR כדי להביא את כל הערוצים שלו אוטומטית
- `app/core/store.py` - שמירת רשימת ה-NVR-ים והמצלמות הבודדות לוקאלית (JSON), בלי ענן
- `app/ui/` - הממשק: סרגל צד עם עץ (NVR -> ערוצים, ומצלמות בודדות) + גריד תצוגה
- `build_exe.bat` - אריזה ל-EXE בודד עם PyInstaller (להריץ על Windows)
- `uninstall.bat` - הסרה נקייה (מוחק את קובץ ה-JSON השמור ומציע למחוק את ה-EXE)

## הרצה רגילה (בלי פקודות)
לחיצה כפולה על `start.pyw`. כדי לקבל אייקון בשולחן העבודה: לחיצה כפולה על `create_shortcut.bat` (פעם אחת).
שגיאות נשמרות ב-`%LOCALAPPDATA%\UniversalCamViewer\app.log`.

## הרצה בפיתוח
```
python -m venv .venv
.venv\Scripts\activate      (Windows)   /   source .venv/bin/activate (Linux/Mac)
pip install -r requirements.txt
python -m app.main
```

## מכשירי XM / Provision CMS (פורט 34567)
ב"הוסף NVR" בחר "סוג חיבור: XM / Provision CMS" והזן את אותם IP, פורט (34567), משתמש וסיסמה כמו ב-CMS3.
נדרש `av` (מותקן דרך requirements.txt) לפענוח H.264.
לאבחון: `python tools/diagnose_nvr.py IP --user X --password Y --stream-test`

## חיבור מחדש
קליק ימני על אריח: **התחבר מחדש** (אותה מצלמה, אותו מקום ברשת), **התחבר מחדש בזרם ראשי/משני**,
ו-**שנה פרטי חיבור** (כתובת, פורט, סיסמה). אחרי שינוי פרטים של NVR כל הערוצים שלו מתחברים מחדש עם הפרטים החדשים.
אחרי 3 ניסיונות עם סיסמה שגויה המצלמה מפסיקה לנסות (כדי לא לנעול את המשתמש ב-NVR). תיקון הפרטים מחבר אותה שוב.

## נגן הקלטות
בחלון ההקלטות: **▶ נגן במלא** פותח נגן מלא ומתחיל לנגן מיד, בלי להוריד את הקובץ כולו.
**קפיצה לכל שעה:** גוררים את הסרגל, או כותבים שעה (למשל 17:10) בתיבה **קפוץ לשעה** ולוחצים Enter. התוכנה מבקשת מה-NVR
להתחיל את ההקלטה מאותה שעה ורק את הקטע הזה מורידים. הפס הדק מתחת לסרגל מראה אילו קטעים כבר זמינים.
קטעים שירדו נשמרים בקבצי ביניים (`%LOCALAPPDATA%\\UniversalCamViewer\\cache`, נמחקים אוטומטית מעל 12GB), ולכן חזרה אליהם מיידית.
אם ה-NVR לא יודע להתחיל מאמצע ההקלטה, התוכנה מזהה זאת לבד (לפי השעה האמיתית שבפריימים) וחוזרת להורדה רציפה,
וקפיצה קדימה ממתינה עד שההורדה מגיעה לשם. **💾 שמור כ-MP4** פעיל אחרי שההקלטה ירדה כולה. **📂 פתח קובץ בנגן** פותח קובץ שכבר יש במחשב.
בנגן: ניגון לאחור, פריים-פריים, מהירויות 0.25x עד 16x, לולאה בין שתי נקודות (A/B), זום, צילום ומסך מלא.
קיצורים: רווח, חיצים, J/L, פסיק/נקודה, [ ], R, A/B/C, S, F. בדיקה מול ה-NVR: `python tools/diagnose_seek.py`.
תקלה בקובץ מקומי: `python tools/diagnose_player.py קובץ.mp4`.

## הערה לגבי Provision CMS3
לפני שמתקינים תוכנה נוספת - כדאי לבדוק בתוך Provision CMS3 עצמו אם יש אופציה
להוספת "Third-party ONVIF Device / IP Camera" ולחבר את המצלמה הסינית ישירות דרכה
(IP + פורט ONVIF + סיסמה). קושחאות NVR עדכניות של Provision-ISR תומכות ONVIF G/T/S
ויכולות להתחבר ל-VMS צד-שלישי שתומך ONVIF.

## מפענח וידאו (כשהתמונה לא עולה במחשב מסוים)

התוכנה יכולה לפענח את הזרם של ה-NVR בשלוש דרכים, והבחירה בתפריט **מפענח וידאו**:

- **PyAV** – הדרך המקורית (ספריות FFmpeg בתוך התוכנה).
- **ffmpeg.exe חיצוני** – תהליך נפרד. שים `ffmpeg.exe` ליד `start.pyw` (או בחר אותו בתפריט). מפענח בתהליך נפרד גם מקל על העומס.
- **OpenCV** – ה-FFmpeg שבתוך OpenCV, בלי קבצים נוספים. הזרם עובר רק בשקע מקומי (127.0.0.1) ולא יוצא מהמחשב.
- **אוטומטי** – הראשון שעובד במחשב הזה.

הפריט **בדוק איזה מפענח עובד במחשב הזה** מפענח קליפ קצר מובנה בכל אחת מהדרכים ומציג מה עבד. הבחירה חלה על חיבור חדש של מצלמה. היא נשמרת ב-`%APPDATA%\UniversalCamViewer\settings.json`, וביומן (`app.log`) מופיע איזה מפענח שימש בפועל.

## גרסה ועדכונים
מספר הגרסה מופיע בכותרת החלון ובתפריט **עזרה**, למשל `v1.1.28`: `1.1` היא הגרסה (משתנה ב-`app/__init__.py`), והמספר האחרון הוא
ה-build של ה-EXE (נקבע אוטומטית בבנייה ב-GitHub; בהרצה מקוד המקור הוא 0 ולכן אין עדכון אוטומטי).

שלוש דרכים לעדכן את ה-EXE (בלי התקנה):
1. **אוטומטי:** כמה שניות אחרי ההפעלה (לכל היותר פעם ב-6 שעות) התוכנה בודקת ב-GitHub אם יש build חדש ושואלת אם לעדכן
   (עדכן עכשיו / אחר כך / דלג על גרסה זו). ההורדה נבדקת מול SHA-256, הקובץ הישן נשמר כ-`UniversalCamViewer.exe.old`,
   והתוכנה נפתחת מחדש לבד. אפשר לכבות: עזרה ← "בדוק עדכונים אוטומטית".
2. **ידני:** עזרה ← "בדוק עדכונים עכשיו".
3. **בלי אינטרנט (רשת מסוננת):** מעתיקים את `UniversalCamViewer.exe` החדש בכונן נייד ואז או עזרה ← "עדכון מקובץ...",
   או שמים אותו ליד התוכנה בשם `UniversalCamViewer.new.exe` (התוכנה תציע לעדכן בהפעלה הבאה). התוכנה מזהה את הגרסה של הקובץ
   ומראה אם הוא חדש יותר או ישן יותר.

**חזור לגרסה הקודמת:** עזרה ← "חזור לגרסה הקודמת" מחזיר את הגרסה שלפני העדכון האחרון (והגרסה הנוכחית הופכת ל"קודמת").
העדכון צריך הרשאת כתיבה בתיקייה של ה-EXE (שולחן עבודה / תיקייה רגילה, לא `Program Files`).

## מגש המערכת (ליד השעון) ולוגו
כשממזערים את החלון הוא עובר לאייקון במגש (ליד השעון) והתוכנה ממשיכה לרוץ ברקע (בזמן הזה הוידאו לא מצויר, כדי לחסוך מעבד).
- **קליק שמאלי** על האייקון: מציג / מסתיר את החלון. הפעלה כפולה של התוכנה פשוט מחזירה את החלון הקיים.
- **קליק ימני:** פתח את התוכנה, הסתר למגש, כל המצלמות במסך מלא, יומן אירועים, הודעות על אירועים (תנועה, זיהוי אדם וכו') כשהחלון מוסתר,
  מזעור למגש (כבה/הפעל), סגירה ב-X ממזערת למגש (כבויה כברירת מחדל), **הפעל עם Windows** (מתחיל מוסתר במגש), בדוק עדכונים, יציאה.
- אירוע חדש כשהחלון מוסתר צובע את האייקון בכתום ומציג הודעה (לכל היותר אחת ל-30 שניות לכל ערוץ).
- הלוגו מצויר בקוד (`app/ui/logo.py`). אחרי שינוי בעיצוב: `python tools/make_logo.py` מייצר מחדש את `app/assets/logo.ico` ששמש את ה-EXE.

## שיתוף פרטים לניהול (אופציונלי)
בהפעלה הראשונה התוכנה שואלת אם לשתף עם המפתח פרטי ניהול: גרסה, שעת הפעלה, מספר התקנה אקראי, ועבור כל NVR/מצלמה
שהוגדרה - השם, ה-IP, הפורט והערוץ. **שמות משתמש וסיסמאות של מצלמות לעולם לא נשלחים**, גם אם השיתוף מופעל - זה
אכוף בקוד (`app/core/telemetry.py`, פונקציית `_camera_row`), לא רק בהבטחה.

אפשר לשנות את ההחלטה בכל רגע: תפריט **פרטיות ← שיתוף פרטים לניהול...**. שם גם רואים אם הדיווח האחרון הצליח,
ואפשר לשלוח דיווח מיידי.

**הקמת הדשבורד (צד המפתח):** `tools/dashboard_apps_script.gs` הוא קוד ל-Google Apps Script שמקבל את הדיווחים וכותב
אותם לגיליון Google Sheets - טבלת "Installs" (שורה אחת להתקנה, מתעדכנת) וטבלת "Devices" (שורה לכל מצלמה/NVR).
ההוראות המלאות בראש הקובץ. אחרי הפריסה, כתובת ה-URL של ה-Web App נכנסת ל-`telemetry_webhook` בהגדרות, או
ל-`DEFAULT_WEBHOOK` ב-`app/core/telemetry.py` לפני בניית ה-EXE. בלי כתובת מוגדרת, שום דבר לא נשלח גם אם מישהו הסכים.
